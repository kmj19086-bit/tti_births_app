# 띠가 아기를 골랐다? — 미신이 한국 출생 통계에 남긴 흔적

산업데이터시각화 개인 프로젝트 · Streamlit 대시보드

- 배포 URL: https://tti-births-app.streamlit.app/
- GitHub: https://github.com/kmj19086-bit/tti_births_app

## 질문

띠 미신(백말띠·황금돼지띠 등)은 정말 출생아 수와 남녀 성비를 바꿨을까?
언제, 어느 띠에서, 누구(몇째 아이)와 어디서 나타났고, 말띠 해인 2026년은 어떨까?

## 데이터 출처

모두 국가데이터처 「인구동향조사」이며, KOSIS 국가통계포털에서 2026-11-24에 열람했습니다.

| 파일 | KOSIS 통계표 | 내용 | 기간 |
|---|---|---|---|
| raw_inh_1b8000f_01.txt | INH_1B8000F_01 | 출생아 수, 합계출산율, 출생성비 | 1970~2025 |
| raw_dt_1b8000g_monthly.txt | DT_1B8000G | 전국 월별 출생아 수, 혼인 건수 | 1981.01~2026.08 (2026년은 잠정치) |
| raw_dt_1b80a01_sex_order.txt | DT_1B80A01 | 성별·출산순위별 출생아 수 | 1981~2025 |
| raw_dt_1b81a19_total.txt | DT_1B81A19 | 시도별 총출생성비 | 1990~2025 |
| raw_dt_1b81a19_order_national.txt | DT_1B81A19 | 전국 출산순위별 출생성비 (검산용) | 1990~2025 |

## 집계 기준

- **띠:** 양력 연도로 붙였습니다. (연도 − 4) mod 12 → 0 쥐, 1 소, … 6 말, … 11 돼지
- **천간 색:** 갑을=청, 병정=적, 무기=황, 경신=백, 임계=흑 (예: 1990 경오=백말, 2026 병오=붉은 말)
- **출생성비:** 여아 100명당 남아 수입니다. 출산순위별 성비는 DT_1B80A01의 남·여 출생아 수로 직접 계산했고, 출산순위 '미상'은 뺐습니다. 셋째아 이상 = 3아 + 4아 + … + 8아 이상
- **편차(추세 제거):** 그 해 값 ÷ (그 해를 뺀 앞뒤 k년씩의 평균) − 1입니다. 출생성비는 퍼센트가 아니라 포인트 차이로 계산합니다. k는 앱에서 1~3으로 바꿀 수 있습니다.
- **연간 혼인 건수:** 월별 혼인 건수를 더한 값입니다.
- **모양 검사:** 바로 앞 해와 다음 해보다 모두 낮은(또는 높은) 해만 '움푹 팬(튀어나온)' 해로 셉니다.
- **우연 확률(순열 검사):** 같은 기간의 모든 해 편차에서 같은 개수를 무작위로 2만 번 뽑아, 그 평균이 관측값만큼 치우치는 비율입니다.

## 검산

`build_data.py`를 실행할 때마다 아래 네 가지를 확인합니다. 하나라도 다르면 실행이 멈춥니다.

1. 월별 출생아 수의 합 = 연간 출생아 수 (1981~2025)
2. 시도표의 전국 출생성비 = 연간 표의 출생성비 (1990~2025)
3. 남아 + 여아 = 연간 출생아 수 (1981~2025)
4. 직접 계산한 출산순위별 성비 = KOSIS 출산순위별 출생성비 (1990~2025)

## 파일 구성

| 파일 | 역할 |
|---|---|
| app.py | Streamlit 대시보드 |
| build_data.py | 원자료 텍스트를 CSV로 정리하고 검산합니다 |
| annual.csv, monthly.csv, order_srb.csv, regional_srb.csv | 앱이 읽는 정돈된 데이터 |
| raw_*.txt | KOSIS 화면에서 옮긴 원자료 |
| requirements.txt | 파이썬 라이브러리 버전 |
| packages.txt | 배포 서버에 한글 글꼴(나눔고딕)을 설치합니다. Matplotlib 한글 표시용입니다. |
| .streamlit/config.toml | 어두운 남색 테마. 차트 색은 이 배경에서 대비·색각이상 구별을 확인했습니다. |

## 실행

```bash
pip install -r requirements.txt
python build_data.py     # (선택) CSV 다시 만들기 + 검산
streamlit run app.py
```

## 대시보드 구성

**위젯**
- 띠
- 지표 (출생아 수 / 합계출산율 / 출생성비 / 혼인 건수, 처음 화면은 흔적이 가장 뚜렷한 출생성비)
- 연도 범위
- 비교 기준 (앞뒤 1~3년)
- 출산순위 그림의 세로축
- 지도 연도
- 월별 비교 연도

**차트**
1. 연도별 선그래프: 띠 해에 정말 달랐나?
2. 편차 막대: 추세를 빼도 남나?
3. 12띠 점 그림: 다른 띠와 비교하면?
4. 출산순위별 성비 작은 그림 (Matplotlib): 누가?
5. 시도 타일 지도: 어디서?
6. 월별 비교선: 2026년 병오년은?

## 주요 결과

- 말띠 해(1978·1990·2002·2014)의 출생성비는 앞뒤 2년 평균보다 평균 +2.3pt 높아 12띠 중 1위입니다. 아무 해나 4개를 골라 이만큼 치우칠 확률은 약 0.5%입니다.
- 1990년(경오, 백말띠) 출생성비 116.5는 1970–2025년 중 최고이고, 첫째아 성비 108.5도 1981–2025년 중 최고입니다.
- 1990년 시도별 성비는 경북 130.6, 경기 111.3으로 지역 차이가 컸습니다.
- 출생아 수에서는 띠 효과가 뚜렷하지 않았고(1990년 출생아는 전년보다 1.6% 증가), 2007년 이후 출생성비는 자연 범위(103~107) 안에 있습니다.

## 해석의 한계

- 상관관계일 뿐 인과관계는 아닙니다. 띠마다 해가 3~5개뿐입니다.
- 띠는 설날·입춘에 바뀌지만, 통계는 양력 연도 기준입니다.
- 편차는 추세가 꺾이는 해에도 커질 수 있어 모양 검사를 함께 봅니다.
- 1970년대 출생성비는 해마다 크게 흔들립니다.
- 2026년은 잠정치이며 8월까지만 있습니다.
